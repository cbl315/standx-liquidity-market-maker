# StandX 做市商激励计划规则总结

## 基本信息概述

| 项目 | 内容 |
|------|------|
| 奖励池 | 每月 5,000,000 代币 |
| 开始时间 | 2026年1月5日 12:00 UTC |
| 交易对 | BTC/USDT |
| 订单上限 | 每账户每边 2 BTC |

## 资格条件

每小时必须满足以下条件：

1. **双边挂单**: 必须同时在买单(bid)和卖单(ask)上挂单
2. **价差要求**: 订单距离中间价(mark price)必须在 10 bps (0.1%) 以内
3. **最低时间**: 每小时内至少保持 **30分钟** 的活跃订单

> 注意: mark price 会根据市场条件持续更新，建议在 10 bps 范围内留有一定缓冲空间，或挂单更紧一些以确保持续符合资格。

## 奖励计算

### 公式
```
每小时 Maker Hours = X × 时间乘数
```

### X 的计算方式
1. 系统每小时不定期多次记录订单大小（取买卖两边较小值，上限 2 BTC）
2. 将所有记录值按**降序**排序
3. X₇₀ = 第70百分位的值（前70%）
4. X₅₀ = 第50百分位的值（前50%）

> 由于降序排序，X₅₀ ≥ X₇₀

### 时间乘数档位

| 档位 | 在线时间 | 乘数 |
|------|----------|------|
| 加成档 (Boosted) | ≥ 42分钟 (70%+) | 1.0x |
| 标准档 (Standard) | ≥ 30分钟 (50%+) | 0.5x |

**最终奖励** = 两个档位计算结果中的**最大值**

## UI 状态指示器

| 颜色 | Maker Hours | 含义 |
|------|-------------|------|
| 深绿色 | > 0.5 | 优秀表现 |
| 浅绿色 | > 0 且 ≤ 0.5 | 积极参与 |
| 灰色 | = 0 | 未活跃 |

> 注意: UI 颜色反映的是**最终赚取的 Maker Hours**，而不是在线时间百分比。你可能达到 70%+ 在线时间（加成档），但如果订单规模较小导致 Maker Hours ≤ 0.5，仍显示浅绿色。

## 获取更多积分的策略

### 核心策略

1. **最大化在线时间**
   - 目标：70%+ 在线时间（每小时 ≥ 42分钟）
   - 效果：解锁 1.0x 乘数档位
   - 建议：保持稳定持续在线

2. **控制挂单价差**
   - 要求：在 mark price 10 bps 以内
   - 建议：挂单比阈值更紧一些，为价格波动留出缓冲
   - 风险：mark price 持续更新，太接近边界可能被判定为超出

3. **保持双边挂单**
   - 必须：同时有 bid 和 ask 订单
   - 建议：两边都要有持续的活跃订单
   - 注意：任一边缺失则该时段不计入

4. **优化订单规模**
   - 上限：每边 2 BTC
   - 建议：尽可能使用较大订单规模（接近 2 BTC）
   - 原因：X 值基于订单大小，更大的订单获得更多 Maker Hours

5. **提高稳定性**
   - 系统**不定期多次采样**
   - 应确保订单在整个小时内保持稳定
   - 避免订单规模大幅波动，以维持较高的百分位值

## 计算示例

### 场景A: 小订单，高在线时间
- 订单规模: 0.5 BTC
- 在线时间: 45分钟 (75%)
- X₅₀ ≈ X₇₀ ≈ 0.5
- 加成档奖励: 0.5 × 1.0 = 0.5 Maker Hours
- 标准档奖励: 0.5 × 0.5 = 0.25 Maker Hours
- **最终: 0.5 Maker Hours (浅绿色)**

### 场景B: 大订单，低在线时间
- 订单规模: 2 BTC
- 在线时间: 35分钟 (58%)
- X₅₀ ≈ X₇₀ ≈ 2.0
- 加成档奖励: 不符合资格
- 标准档奖励: 2.0 × 0.5 = 1.0 Maker Hours
- **最终: 1.0 Maker Hours (深绿色)**

### 场景C: 大订单，高在线时间（最佳）
- 订单规模: 2 BTC
- 在线时间: 45分钟 (75%)
- X₅₀ ≈ X₇₀ ≈ 2.0
- 加成档奖励: 2.0 × 1.0 = 2.0 Maker Hours
- 标准档奖励: 2.0 × 0.5 = 1.0 Maker Hours
- **最终: 2.0 Maker Hours (深绿色，最优)**

## 关键要点总结

| 优先级 | 策略 | 影响 |
|--------|------|------|
| 最高 | 在线时间 ≥ 42分钟 | 解锁 1.0x 乘数 |
| 高 | 订单规模接近 2 BTC | 直接增加 X 值 |
| 高 | 保持稳定的订单规模 | 提高百分位值 |
| 中 | 挂单价差留有缓冲 | 确保持续符合资格 |
| 中 | 双边同时挂单 | 基本要求 |
